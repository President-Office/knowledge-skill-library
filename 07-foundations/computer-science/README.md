# 计算机基础学习地图

## 定位

计算机基础帮助理解程序如何表达问题、如何在计算机上运行、如何保存和传递数据，以及系统如何在资源限制和故障下保持正确。它是软件工程和 AI 应用的底层支撑，不是某一种语言或框架的教程。

本页是学习地图，不代表本知识库已覆盖每个主题的完整教材。通用工程原则、数据库、面向对象和技术栈的现有笔记入口见 [[07-foundations/README]]。机器学习、生成式 AI、模型和 Agent 专题继续由 AI 知识库维护；这里仅介绍理解它们所需的通用计算基础。

## 建议学习路线

### 1. 编程与计算思维

- 变量、表达式、控制流、函数、模块、类型和错误处理；
- 把问题分解成输入、状态、变换和输出；
- 阅读、调试、测试和维护已有程序。

重点不只是熟悉语法，而是能准确表达问题、约束和行为。

### 2. 数据结构与算法

- 数组、链表、栈、队列、哈希表、树、图和堆；
- 搜索、排序、遍历、动态规划和常见算法范式；
- 时间与空间复杂度，以及数据规模变化时的性能取舍。

学习目标是能根据访问模式和约束选择合适方案，而不是背诵题解。

### 3. 离散数学与计算理论

- 命题逻辑、集合、关系、函数、组合计数和图论；
- 自动机、可计算性、复杂度与不可解问题的基本概念。

这些概念支撑算法分析、协议定义、数据库建模和程序正确性推理。

### 4. 计算机组成与操作系统

- 二进制表示、CPU、内存、缓存、存储和 I/O；
- 进程、线程、调度、虚拟内存、文件系统和权限；
- 并发、同步、死锁、资源竞争与故障隔离。

理解这些内容有助于诊断性能、并发、部署和资源使用问题。

### 5. 计算机网络

- 分层、寻址、路由、DNS、TCP/UDP、TLS 和 HTTP；
- 超时、重试、幂等、连接池、代理和服务发现；
- 延迟、吞吐、丢包、部分失败和网络信任边界。

网络调用不是本地函数调用：远端可能超时、重复处理或不可达，系统设计必须明确处理这些情况。

### 6. 数据库与数据系统

- 关系模型、SQL、索引、约束、事务和隔离；
- 键值、文档、搜索、列式和图等数据模型的适用边界；
- 备份恢复、数据迁移、一致性和读写负载。

已有数据库学习入口见 [[07-foundations/data/database-basics]]、[[07-foundations/data/sql]]、[[07-foundations/data/database-transaction]] 和 [[07-foundations/data/databases/README]]。

### 7. 编程语言与编译运行时

- 语法、类型系统、作用域、内存管理和运行时；
- 解释、编译、链接、包管理和构建产物；
- 静态与动态类型、垃圾回收和 ABI 等机制的作用及代价。

目标是能理解工具链如何把源代码变成可运行程序，并定位构建或运行时错误。

### 8. 并发与分布式系统

- 共享状态、锁、原子操作、消息传递、竞态和死锁；
- 客户端/服务器、复制、分区、缓存和异步消息；
- 超时、重试、幂等、重复投递、部分失败、顺序性和一致性取舍。

分布式系统是网络、并发、数据和故障处理的交叉领域。它帮助解释为什么网络分区、节点故障和重复操作会影响应用正确性，而不仅是性能。

### 9. 软件工程与系统设计

- 需求、接口、模块边界、版本控制、测试、持续集成和发布；
- 可维护性、兼容性、可观测性、可靠性、安全和技术债；
- 在变化成本、复杂度、交付速度和风险之间作出可解释的取舍。

入口见 [[07-foundations/engineering/software-engineering]] 和 [[07-foundations/agile/README]]。

### 10. 安全基础

- 认证与授权、最小权限、输入校验、密钥管理和安全更新；
- 常见威胁建模、审计、数据保护和安全失败处理。

安全不是上线前单独补的一道工序，而是贯穿需求、设计、实现、部署和运行的约束。

### 11. 人机交互与无障碍

- 用户目标、信息架构、反馈、错误预防和可发现性；
- 键盘可操作性、语义结构、对比度和辅助技术兼容；
- 用真实使用任务验证界面，而不是只凭开发者偏好评判。

软件的正确性还包括用户能否理解并完成任务；可访问性和可用性应在需求与验收阶段考虑。

## 当前覆盖边界

这是一张学习地图，不表示目录中已经为每个学科准备了完整教材。现有笔记对数据库、数据建模、面向对象、工程原则和部分架构有较多支撑；算法、计算机组成、操作系统、网络协议、编程语言理论、并发/分布式系统和安全目前主要是路线纲要，后续可按项目遇到的真实问题逐篇补充。

## 建议优先补充的概念卡

1. **数据结构与算法**：复杂度、常见结构的访问特性、搜索/排序和图算法。
2. **计算机组成与操作系统**：内存层级、进程/线程、虚拟内存、文件系统和并发。
3. **网络与分布式系统**：DNS、TCP/TLS/HTTP、超时/重试/幂等、复制和一致性。
4. **编程语言与构建链路**：类型、内存模型、编译/链接、依赖和构建。
5. **安全与可靠性**：身份、权限、威胁建模、备份恢复、故障隔离与恢复。

按真实项目遇到的问题逐项沉淀，并为每张概念卡链接一个可观察或可验证的代码/系统例子；不以一次性补齐百科为目标。

## 与 AI 的关系

AI 工程建立在计算机基础之上：模型服务要经过网络和身份权限边界；RAG 依赖数据处理、索引和检索；Agent 工具需要理解操作系统、进程、文件、API 和失败恢复；推理成本和延迟受硬件、并发、缓存及调度影响。

学习 AI 时遇到底层问题，应沿此地图回到相应基础主题，而不是只依赖框架接口或提示词技巧。

## 学习方法

1. 选择一个具体问题或小型程序作为贯穿案例。
2. 先建立概念模型，再通过实验、日志或源码观察验证。
3. 记录约束和取舍，不只摘抄定义。
4. 把临时版本/命令放入对应技术栈笔记；本地图只保留相对稳定的知识入口。
5. 按实际项目需要深入，不要求所有主题一次学完。
